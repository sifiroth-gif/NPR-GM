# NPR-GM — правила разработчика
Это исследование модели, не игровой чат. Начать с README.md, docs/RESEARCH_PLAN.md, docs/JOURNAL.md. Продолжить первый незавершённый пункт. Игровые репозитории NPR и Bleach-RPG- только читаются, по закреплённым SHA; никакой записи TURN, изменения правил или публикации скрытых игровых сведений. Все эксперименты на синтетических ситуациях либо изолированных копиях. Не переносить архивы в сторонний сервис без явного согласия. Не считать черновик, тестовый эталон, smoke test или синтетическую сцену доказательством качества модели. Не обучать на eval и его парафразах. Не запускать платное вычисление. После каждого пакета записать версии, команды, измерения, ограничения и следующий шаг в JOURNAL. При отсутствии GPU не имитировать обучение. Локальный запуск не требует API-ключа. Не удалять исходные записи, не помещать секреты, веса и частные корпуса в git.

Публичная редакция v0.2: только авторский код, методология, библиография и синтетика. Не публиковать закрытые архивы, манифесты, скрытый канон, PDF, ключи, веса или raw runs. Публичные 24 кейса и их парафразы исключить из обучения; для независимой оценки нужен новый закрытый локальный holdout.

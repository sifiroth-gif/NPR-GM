# R6-S1: контракт модели и изолированного движка
26.11.2026. Синтетический лабораторный прототип, не интеграция с живой кампанией.

## Граница ответственности
Сверен текущий GM_CORE исходного NPR только чтением: NEXT, preflight, npr-turn/2, CAS TURN и правила отставания свёртки. В живой игре сначала игрок заявляет действие, ведущий проверяет источники, применяет механику, проводит preflight; текущий регламент записи остаётся неизменным. Этот эксперимент НЕ заменяет TURN и не меняет порядок действующей игры.

В sandbox доверенный хост заранее интерпретирует заявку, задаёт разрешённые исходы, источники, цену, время. Модель получает только публичный срез и список допустимых исходов. Она может запросить read_source по ID и предложить один из разрешённых вариантов. Произвольные файловые пути, shell, SQL, цены, время, дельты запрещены. Неизвестный и скрытый ID имеют одинаковый ответ. Ограничены число запросов и объём JSON; повторные ключи и лишние поля отклоняются. Цитировать можно только прочитанные доступные источники, обязательные источники должны быть прочитаны. Версия состояния и ID хода проверяются до применения. Изменения ресурсов и времени берутся из доверенного исхода, а не из модели. Повторный ход и устаревшие параллельные кандидаты отклоняются; получение receipt не повторяет действие. Все операции только в памяти.

## Проза и ограничения
Модель предлагает scene_draft, но commit возвращает только доверенное player_text, статус черновика unreviewed_not_published. Это намеренно консервативная лабораторная граница: не доказано, что автоматический фильтр понимает смысл прозы. Художественный текст должен пройти отдельный preflight C01–C11; будущий реальный адаптер должен сохранить причинность, знания, автономию NPC, источники и полномочия игрока. Синтетический host выбирает заранее разрешённые исходы; ещё нет реального разрешения механики, RNG, автономных событий, долговременной SQLite-памяти, durable CAS, интеграции с NEXT/TURN, либо управления полноценным диалогом с моделью. Не выдавать этот код за готовую игровую систему. Не обучать на unit fixtures и демонстрации.

## Запуск
```sh
python -m npr_gm.sandbox
python -m unittest discover -s tests -v
```
Следующий шаг: отдельный транспорт loopback для tool calls, реальные структурированные кандидаты и тренировочная выборка (не совпадающая с eval/fixtures), проверяемое отображение на оригинальный протокол NPR в изолированной копии. В промышленной системе необходимы durable receipt, CAS, восстановление после сбоя, выборка по источникам, семантическая проверка player-safe прозы. Ноутбук пока не требуется.

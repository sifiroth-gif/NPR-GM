## Approach

Use PyTorch CUDA, Transformers Qwen3_5ForConditionalGeneration, PEFT, bitsandbytes NF4 double quant, rank 8 alpha 16, text attention projections only, frozen base, gradient checkpointing, batch 1, gradient accumulation 1 for smoke, context 512. Conservative limited-projection QLoRA variant, not all-linear. BF16 if supported, FP16 + scaler otherwise. A full multimodal checkpoint may exceed available VRAM; this is a hypothesis, not a benchmark. If load/forward fails or OOM, record evidence, then consider official 2B or validated text-only conversion; do not silently substitute weights. No remote code, no upload, no raw logs. Script requires explicit --run; otherwise only checks data and config. Pinned exact HF commit required, not the GGUF repository revision.

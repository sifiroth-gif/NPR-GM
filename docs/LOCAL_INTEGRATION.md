# R6-N2 — local source grants and original preflight smoke

The previous paired diagnostic supports mandatory host prefetch, not automatic trust in arbitrary documents. SourceBroker grants an opaque ID to one explicitly host-reviewed player-visible excerpt of a file at one exact Git commit. Grant contains path, exact blob SHA, inclusive 1-based line range (bytes.splitlines(keepends=True)), SHA256 of exact excerpt bytes, visibility. Host must resolve latest source and inspect context/perspective before granting; a digest is integrity, not truth or visibility proof. Never make grants from model requests or automatically grant entire mixed documents. A model receives ID/text only; hidden, absent, unreviewed, stale or mismatched grants do not yield text. Shared read budget; mandatory prefetch fails closed and a partial retrieval failure poisons the broker, clears its citation ledger and requires a new turn/broker; explicit citations are still required. Maximum 8 reads, 1 MB per source blob, 8 KB per excerpt, 100 lines. No remote access, no durable state, no production transport integration yet. Build a fresh broker for each accepted cursor; if state changes, discard all grants and rebuild. Manually resolve conflict and source provenance; no automated semantic redaction.

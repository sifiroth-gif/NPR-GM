## Local bridge
npr_gm.npr_bridge reads exact committed NEXT/TURN from a deliberately isolated local Git copy. Requires full code and state commit SHA, checks content blob SHA, rejects fold/state errors and stale or changed TURN without receipts. Optional receipt commits must be ancestors of the pinned state, ordered, exact blobs, match predecessor chain and latest TURN; for a folded anchor the first receipt's parent must have exact predecessor blob. Original overlay.project handles turn order, local projection and invalidation of stale derived fields; no duplicate implementation of dice/resource calculations. Original preflight.inspect handles mechanics and manual review cues. Code is extracted from pinned Git archive into temporary directory; no checkout mutation, no writes to game state, no live publication, no network in bridge itself. Only trusted original code: subprocess isolation is not a hostile-code sandbox. Input draft must already be original npr-turn/2, built by trusted host and reviewed separately; model's sandbox candidate cannot be converted into a delta automatically. Only aggregate status/counts leave CLI, not private state, prose, source references or raw errors.

Example (local isolated clone, actual commits supplied locally):
```sh
python -m npr_gm.npr_bridge --isolated-copy --root /path/to/isolated-npr --code-rev FULL_CODE_SHA --state-rev FULL_STATE_SHA --draft private_data/draft.json
```
For a confirmed lag chain add ordered --receipt-commit FULL_SHA for each accepted TURN commit, --used ID for explicitly activated capabilities. Never infer receipts from mere model messages. If a changed predecessor or incomplete chain is found, refresh/resolve rather than guess. Local read-only preflight is not write CAS, not proof of semantic correctness, not a fold, not autonomous simulation. It does not publish or apply a candidate.

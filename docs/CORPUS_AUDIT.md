# Инвентаризация корпуса: публичная версия

Две длительные игровые кампании инвентаризированы только чтением. Полные манифесты, идентификаторы сохранений, пути архивов и первичные записи остаются в локальном исследовательском комплекте. Содержание и разметка ещё не проверены полностью; наличие файлов не доказывает полноту истории.

План: выбрать 30–50 эпизодов, установить источник, предшествующий контекст, заявку, ответ, дельту (если есть), явные поправки и качество. Не считать последующий ход согласием. Дедуплицировать по источнику и группе соседних сцен. Split по группам до обучения. Публиковать только синтетические примеры без узнаваемых деталей исходных кампаний; частные выборки и результаты хранить локально. Права на данные проверять отдельно.

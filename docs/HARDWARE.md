# Вычислительные требования

Измерения не проведены: неизвестны RAM/VRAM компьютера и фактический свободный объём памяти телефона. Чистые 4-битные веса для 4B ~2 ГБ, 9B ~4.5 ГБ без метаданных, KV/cache, runtime, ОС и контекста; реальные GGUF и peak RSS измерить. Начать с 4B, 8K, затем 16K при достаточной памяти. Не использовать номинальный объём RAM как доступный бюджет. Замерять на реальном устройстве 3–5 последовательных генераций и длительную серию, p50/p95, токены/с, температура, сбои. Для QLoRA сначала 10 шагов на 128–512 токенах/пример, измерение peak VRAM, затем увеличить длину до реально нужной. Не обещать 4B на любой бесплатной T4 или 9B на телефоне. Локальная эксплуатация без API/аренды, электричество и имеющееся оборудование остаются затратами. В контейнере подготовки доступ к модельным весам и GPU не подтверждён; обучение не выполнено.

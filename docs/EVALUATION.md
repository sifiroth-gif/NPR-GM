# Протокол оценки v0.1

Публичный synthetic_eval.jsonl: 24 независимых ситуации, 12 групп по 2 варианта. Разработчик может знать критерии, но модель получает только context/player/schema. Fixtures содержат эталон и ошибочный ответ для тестирования валидатора, никогда не отправляются при реальном inference. Автоматические проверки: JSON, типы, clock_advance, факты из whitelist, action IDs, простые forbidden substrings (низкая полнота, ложные срабатывания возможны). Они не доказывают отсутствие семантической ошибки. Ручная оценка по blind model IDs: агентность, источник/знание, причинность, цена, темп, психология, проза, саспенс (0–4: 0 грубая ошибка, 1 существенный дефект, 2 приемлемо с исправлениями, 3 хорошо, 4 убедительно). Hard gates: добровольное решение игрока, раскрытие скрытого знания, существенная подмена ресурса/кости, необоснованный реткон — отказ. Все критерии и ответы сохраняются для повторной оценки. Неприменимые шкалы NA, не ноль. Художественные рубрики не валидированы; по возможности два независимых оценщика, согласие/разбор расхождений. Оценить полные эпизоды, не только слова.

Порог пилота: 24/24 валидная схема после не более одного явно учтённого исправления, 0 критических ошибок по ручной проверке; средняя художественная оценка >=3/4 по применимым шкалам. Если не выполнен — модель не принимается для автономного ведения, но можно продолжить исследование. 24 случая недостаточны для сильного статистического вывода; расширить held-out после пилота новыми группами, не подгонять под тест.

Публичная редакция v0.2: только авторский код, методология, библиография и синтетика. Не публиковать закрытые архивы, манифесты, скрытый канон, PDF, ключи, веса или raw runs. Публичные 24 кейса и их парафразы исключить из обучения; для независимой оценки нужен новый закрытый локальный holdout.

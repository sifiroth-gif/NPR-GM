# R3 — локальная подготовка корпуса
25.11.2026. Публичный код, частные входы/выходы. Не переносить реальные игровые тексты в публичный GitHub или GitHub Actions. Пакет не обучает модель.

## Извлечение
Создать отдельную локальную read-only копию исходного игрового репозитория; закрепить SHA, полученный владельцем или разработчиком из первоисточника. Находясь в NPR-GM, выполнить:

```sh
python -m npr_gm.corpus extract --root /path/to/source-copy --revision FULL_COMMIT_SHA --campaign opaque-a --session 11 12 13 14 --output private_data/candidates.jsonl
```

Если --session не указан, извлекаются все поддерживаемые архивные JSONL. Исходный репозиторий не изменяется, используется git show закреплённой ревизии. Выход создаётся только под private_data, без перезаписи. Программа не печатает прозу или ID, только число кандидатов, наличие дельт, OOC и approved=0. Нельзя использовать candidate JSONL как готовое обучение. Записи содержат исходные тексты и внутренние дельты исключительно для локального разметчика. Не добавлять их в Git. .gitignore не является защитой от намеренного добавления. Для архива второй кампании пока нет автоматического адаптера: рабочий Markdown-журнал не гарантирует полную пару реплик, нужна отдельная привязка к первичным источникам.

## Разметка
Восстановить состояние на момент заявки из предшествующих авторитетных записей; не включать будущую информацию или текущую delta_after. Оставить исходный ответ как материал проверки, вручную заполнить chosen только если он подтверждён или подготовлена корректная редакция. Использовать C01–C11, ANNOTATION_GUIDE.md. Сгруппировать близкие сцены и арки, не разделять соседние вариации и парафразы. Сначала закрепить независимые группы holdout/dev и потом train. Указать для каждого утверждённого ряда group_id, split, rights_status=approved_for_training, reviewer_id, semantic_leakage_review=pass, snapshot_review=verified_as_of_turn, review_status=approved, train_eligible=true, applicable_ids, hard_results, soft_scores, key_competence. Требуется реальная проверка, а не механическое присвоение полей. Пример из fixtures не является обучающим.

## Экспорт
Локальный split-map.json отображает окончательные идентификаторы групп в train/dev/holdout. Нужна внешняя фиксация хеша и разделения до разметки. Экспорт проверяет разрешение на обучение, наличие исходника, отсутствие exact overlap с публичным smoke, пройденные hard gates, выбранную компетенцию >=3, отсутствие повторов source/pair. Парафразы и связанные группы проверяет эксперт; код не может доказать отсутствие утечки. Вывод только train, dev/holdout не экспортируются. При отсутствии утверждённых записей команда завершается ошибкой. Никаких выдуманных утверждённых примеров.

```sh
python -m npr_gm.corpus export-sft --reviewed private_data/reviewed.jsonl --split-map private_data/split-map.json --output private_data/sft-train.jsonl
```

Текущий экспорт — простые chat messages для первоначальной текстовой специализации; не производственный TURN и не окончательный тренировочный шаблон. В R5 применить chat template выбранной модели, loss только на assistant, измерить токены и утечки. Отдельный структурированный набор кандидатов действий/вызовов инструментов ещё необходим.

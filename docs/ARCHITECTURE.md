# NPR-GM: разделение функций

Модель получает правила, актуальную заявку и выбранные источники, предлагает намерения NPC, вызывает ограниченные read-only инструменты, готовит черновик. NPR остаётся единственным авторитетом фактов, ресурсов, RNG, календаря, принятого хода и журналов. Модель не записывает Git/SQLite. Сервер: context -> candidate -> preflight -> staging fold/check -> commit -> player-safe prose. Текущий тестовый контракт упрощён до {scene, facts_used, actions, clock_advance}; это лабораторная схема, не замена npr-turn/2. Реальный адаптер должен принимать именно оригинальный TURN, а не выдуманную новую механику.

Локальная модель через llama.cpp OpenAI-compatible endpoint на 127.0.0.1. Endpoint вне loopback по умолчанию запрещён. Для исследовательского benchmark серверу посылается только синтетический контекст. Скрытый контекст никогда не в клиентскую карточку. Изолированный стенд NPR закреплён по SHA; интеграция после baseline. В будущем — инструменты read_source, get_entity, get_capability, resolve_check, propose_turn; не произвольный shell/SQL. Минимальный прототип сначала текстовый CLI, Android после измерений. Нельзя обещать, что 4B выдержит полноценные 40 КБ NEXT плюс длинную генерацию; токенизировать и измерять фактический контекст.

Публичная редакция v0.2: только авторский код, методология, библиография и синтетика. Не публиковать закрытые архивы, манифесты, скрытый канон, PDF, ключи, веса или raw runs. Публичные 24 кейса и их парафразы исключить из обучения; для независимой оценки нужен новый закрытый локальный holdout.

## Локальный научный справочник
R3-K: read-only knowledge_search(domain, query, scope) возвращает source_id, card_id, факт, границы применимости и статус проверки. Проектный интерфейс, ещё не реализован поиск. Сначала проверяемый компактный индекс и извлечение небольшого числа карточек; NPR сохраняет авторитет игрового состояния. Не отправлять контекст приватной игры в сетевой поисковик. Черновые карточки не считать медицинским прогнозом или установленным игровым фактом.

R3: 60 черновых научных карточек, локальный лексический поиск остаётся демонстрационным. Архивный импорт read-only по закреплённому commit; delta_after никогда не подставлять как предходовое состояние. Экспорт тренировочных данных — отдельный этап после разметки и проверки прав.

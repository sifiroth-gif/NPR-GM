# NPR-GM

Исследовательский проект независимого ведущего текстовых RPG. Цель — локальная компактная модель с внешней механикой и памятью, без обязательных платных API. Пока не обученная модель и не мобильное приложение.

Публичный репозиторий: только авторский код, методология, библиографические ссылки и синтетические примеры. Частные кампании, исходные PDF, скрытые данные, ключи, веса и результаты частных экспериментов не публикуются.

## План и продолжение работы
Горизонт — четыре дня, нулевой дополнительный бюджет. R0: загрузка безопасного пакета и CI; R1: литература и компетенции; R2: выбор 4B/9B и замеры устройства; R3: разметка локального корпуса; R4: независимый holdout и реальные baseline-прогоны; R5: SFT/QLoRA при наличии GPU; R6: сравнение и экспорт, CLI-интеграция на копии NPR. Не изменять живые игры. Не публиковать закрытые данные. Публичные кейсы не использовать для обучения. При отсутствии GPU передать prompt+tools прототип, не имитировать обучение.

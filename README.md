## Архитектура
Модель получает текущую заявку и релевантные источники, вызывает разрешённые read-only инструменты, формирует кандидат сцены. NPR — авторитет состояния, RNG, времени, ресурсов, канона и сохранения. Валидация до публикации; одна подтверждённая запись хода. Модель не пишет в Git/БД. Qwen3.5-4B первый кандидат, 9B контроль; окончательный выбор по испытаниям. llama.cpp/GGUF — первичный локальный inference; PEFT/QLoRA — экспериментальное обучение. Проверять совместимость, лицензию, revision и квант.

## Оценка
H1: адресный контекст и инструменты улучшают точность. H2: адаптер улучшает протокол и прозу относительно той же модели с теми же инструментами. H3: 4-bit уменьшает память при приемлемом качестве. Одинаковые параметры и split. Метрики: схема, агентность, источники знания, цена, кость, время, автономия NPC, темп, причинность, русский литературный стиль, саспенс, p50/p95, токены, RAM. Ручная рубрика 0–4; экспериментальная цель >=3/4 и ноль критических ошибок на закрытом тесте. Публичные тесты и парафразы не использовать для обучения. Закрытый holdout создать заранее. Fixture не inference. Не выдавать эксперимент за доказательство эквивалентности облачным моделям.

## Изоляция, публичность, стоимость
NPR и другие действующие игры только читать, по возможности по закреплённым локально SHA. Не менять живые ветки, курсоры, правила, сохранения. Эксперименты на синтетике или изолированных копиях. Публично только авторский код, методология, библиографические ссылки, синтетика. Не публиковать закрытые архивы, PDF, личные данные, скрытый канон, ключи, приватные манифесты, веса и raw runs. private_data/, runs/, weights/ — локально, вне Git. Не отправлять закрытые данные сторонним сервисам без разрешения. Не запускать платные задачи. Доступность бесплатного GPU и возможность локального исполнения пока не подтверждены.

## Запуск проверок
Python 3.10+; зависимости валидатора — стандартная библиотека.

```sh
python -m unittest discover -s tests -v
python -m npr_gm.evaluate --check-data
python -m npr_gm.evaluate --fixture --output runs/fixture.jsonl
# Только после установки совместимой версии llama.cpp и получения GGUF:
llama-server -m /path/to/model.gguf -c 8192 --host 127.0.0.1 --port 8080
python -m npr_gm.evaluate --model local-gguf --output runs/baseline.jsonl
```

Fixture — проверка эталонов и валидатора, не inference; выходной файл не перезаписывается, использовать новое имя для повторного запуска.
